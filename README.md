# PA1 – Interactive Task List  
**Author:** Tyler  
**Course:** ICSI 418Y – Software Engineering  

## Description
This project is a simple interactive task management web app using HTML, CSS, and JavaScript.  
Users can add tasks, choose a priority, mark tasks as completed, and delete tasks.  
Tasks exist only while the page is open.

## How to Run
1. Clone the repository  
2. Open the folder in Visual Studio Code  
3. Open `index.html` in a browser or use Live Server (I also use command in terminal "start index.html) 

## Features
- Add tasks  
- Priority selection (Low, Medium, High)  
- Bold priority colors  
- Completed task styling  
- Delete tasks  
- Form validation
